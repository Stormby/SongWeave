# SongWave Synthpop 80

Universal macOS 13+ VST3 and standalone app. Pick a song reference, preview the arrangement, lock a favourite part, and use Variation or New song. Drag a part, a section or the entire song into Live. The generative model samples original scale-degree phrases with profile-specific harmony, drum programming, bass articulation and arrangement. The reference names identify musical directions. The distributed instrument contains no artist recordings or Avenger expansion content.

## Using Avenger 2.5

In SongWave choose Virtual ports (Ableton Live). Enable Track for the six SongWave Synthpop 80 inputs in Live’s MIDI settings. Create six MIDI tracks with one Avenger instance each, select the matching SongWave input on each track, and set Monitor to In. Melody, Chords, Bass, Arp and Response default to MIDI channels 1–5. Drums defaults to 10. Choose Omni or the matching receive channel in each destination. For recording into Live, arm receiving tracks and record the Arrangement. For file export, start with Whole song and drag All parts.

Under the song selector open **Avenger 2.5 sounds & drum setup**. Each reference has a suggested expansion and six sound descriptions. BA, LD, PL, ST and similar prefixes are Avenger browser categories. The adjectives describe what to listen for. Audition the named SQ example separately as a tonal reference. For playing SongWave use a single playable sound for each lane. Bypass Avenger’s internal arp when playing the written arpeggio. MIDI contains no patch-change messages, so the chosen sound stays selected.

Start Drums with a kit from Italo Disco 2. Disable DRUM SQ, enable the drum module and check that external notes play individual samples. The defaults use MIDI numbers 36 (kick), 38 (snare), 39 (clap), 42/46 (closed/open hats), 43/41 (two percussion slots for toms), 37 (rim or hand percussion) and 47 (crash). Use Avenger’s sample browser to put the desired hits in those slots, or change each trigger note in SongWave. Assigning an occupied note swaps the two voices. The map is saved with the project and applies to playback and MIDI export. Choose a drum voice and Export this drum voice to get a separate aligned clip.

## Listening references and design choices

Cretu and Sandra share a production lineage. The Samurai profile leaves a measured space after the lead for a brass answer. Secret Land stretches the chords and uses softer, sparser drums, while Maria Magdalena uses octave movement and a bright offbeat part. Each of the seventeen profiles specifies its own rhythm cells and instrumentation suggestions. Tempos, keys and arrangements are creative defaults.

Modern Talking choruses add a high second harmony to the response. Alphaville's Sounds Like a Melody uses a rapid repeating part and a string answer, informed by the recording’s string-section credit. Pet Shop Boys' Domino Dancing uses displaced bass attacks and hand percussion, whereas It’s a Sin puts octave-spaced orchestral punctuation at section entrances. Heart gives a repeated hook to a steady disco pulse.
